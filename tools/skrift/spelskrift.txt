# Spelskrift: pikselskrifta til «Aasen: Språkvandringa».
# Teikna for hand, glyf for glyf (sjå tools/skrift/README.md og bygg.py).
#
# Rutenett: «#» er ein piksel, «.» er tomt. Rekkjene går ovanfrå og ned. Den siste
# rekkja står på grunnlina, med mindre «ned=N» seier at dei N siste rekkjene ligg
# under grunnlina (g, j, p, q, y, komma). «lyft=N» lyftar glyfen N rekkjer (strek,
# hermeteikn). «breidd=N» set framsteget (N pikslar) for glyfar utan rutenett.
# Framsteget er elles breidda + 1 (ein piksel luft til høgre).
#
# Mål: store bokstavar 9 pikslar høge, små 6 (x-høgda), oppstrekar 9, nedstrekar 3.
# Aksentar på små bokstavar ligg i rekkje 8 og 9 over grunnlina, på store i 11 og 12.
#
# Samansette glyfar: «glyf á = a + akutt» set merket over basen, sentrert, med éi
# tom rekkje imellom. «dx=N» flyttar merket sidelengs.

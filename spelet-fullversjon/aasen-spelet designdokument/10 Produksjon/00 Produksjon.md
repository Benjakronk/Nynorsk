# Produksjon

Fanene under denne handlar om korleis spelet skal byggjast. Dei andre fanene i dokumentet seier kva spelet er. Desse seier i kva rekkjefølgje det blir laga, korleis det skal sjå ut og høyrast ut, korleis menyane er bygde, og korleis innhaldet blir flytta over i datafiler.

| Fane | Innhald |
| --- | --- |
| 1. Produksjonsplan | Fasane frå overgangen frå prototypen til utgjeving, med krav for når kvar fase er ferdig |
| 2. Grafikk og stil | Retningslinjene frå prototypen og kva heile spelet treng av grafikk |
| 3. Lydeffektar | Liste over lydeffektar med ID og fase |
| 4. Menyar og kontrollar | Skjermane, vindauga og tastane |
| 5. Datamodell | Oppdraget til agenten som lagar datafilene |

Tilgjengelegheit kjem i fase 12 i planen og har inga eiga fane enno.
